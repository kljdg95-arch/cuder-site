CUDER site - راهنمای انتشار رایگان (GitHub Pages)
1) یک مخزن (repository) جدید در GitHub بسازید و همه‌ی فایل‌های همین پوشه را در ریشه‌ی آن آپلود کنید (خود پوشه را نه؛ محتویاتش را).
2) در Settings > Pages شاخه‌ی main و پوشه‌ی root را انتخاب کنید.
3) فایل CNAME (حاوی cuder.ir) از قبل هست. در DNS دامنه، رکوردهای A را به آی‌پی‌های GitHub Pages و www را با CNAME به <username>.github.io وصل کنید.
4) ورود به سایت: index.html
   BizFlow: /bizflow/   DownFlow: /downflow/   حساب: /account.html   پرسش‌های رایج: /faq.html
نسخه وب هر دو محصول (PWA) فقط روی HTTPS قابل نصب است؛ GitHub Pages این را فراهم می‌کند.
